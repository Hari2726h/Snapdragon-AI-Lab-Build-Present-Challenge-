## Project title

Rakshak Edge: A Private On-Device Social-Engineering Firewall for Snapdragon PCs

## Brief description

Rakshak Edge is a local AI safety assistant for suspicious messages and conversation threads. It detects urgency, impersonation, credential theft, risky URLs, and Indian payment signals, then explains the evidence and recommends a safer verification path. Its conversation engine reveals a scam's progression from identity setup to isolation and extraction, even when each message looks less suspicious alone. The working hybrid pipeline combines transparent security rules with a trained multilingual semantic classifier. It reaches 94.44% on the model holdout and 97.78% on a separate balanced 45-case end-to-end suite, with every error disclosed. A Snapdragon production profile upgrades the compact reference model to an INT8 encoder accelerated through ONNX Runtime QNN on the Hexagon NPU. The demo works fully offline with no account, telemetry, cloud upload, or stored message history.

## One-line pitch

Rakshak Edge reveals how a scam develops across messages and intervenes before the user pays or shares a secret, entirely on device.
